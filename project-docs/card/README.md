# Calling card QR

`connect-qr.svg` (vector, transparent background, for the printer) and `connect-qr.png` encode **https://michaelplant.com/connect**, generated with the `qrcode` npm library, error correction M.

Before printing:
1. Deploy the site so `/connect/` is live.
2. Scan the QR on the **printed proof** with an iPhone and an Android phone. Both should open the Connect page, and "Save Mike to contacts" should add the contact.
3. Don't restyle or AI-render the code. Keep the quiet zone (white border) and print at ≥ 0.75 in (19 mm).
