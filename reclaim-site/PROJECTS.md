# projects.json

Real Reclaim jobs only. Shoot before, during, and after from the same spot, in the same light.

```json
[
  {
    "service": "porches",
    "title": "Front porch floor and column bases",
    "where": "Lakewood, near Madison",
    "year": 2026,
    "note": "Two column bases had rotted through. Saved the original columns with dutchman patches.",
    "photos": [
      { "src": "/assets/img/jobs/porch-1-before.jpg", "label": "Before" },
      { "src": "/assets/img/jobs/porch-1-during.jpg", "label": "During" },
      { "src": "/assets/img/jobs/porch-1-after.jpg", "label": "After" }
    ]
  }
]
```

Photos go in `src/assets/img/jobs/`. `service` matches a key in services.json (porches, trim-and-rot, stairs-and-railings). Each service page shows its own jobs, and the home page shows the latest three. Get the owner's OK before posting their house, and leave out the street number.
